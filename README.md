# AI Hub - AI Tools Directory

A comprehensive directory of AI tools across multiple categories including image generation, video creation, text/code generation, productivity, audio/music, and more.

## Quick Start

### Option 1: Using the Start Script (Recommended)
1. Open the integrated terminal in VS Code (Ctrl+` or View → Terminal)
2. Run the start script:
   ```bash
   ./START.sh
   ```

### Option 2: Manual Setup
1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to the URL shown in the terminal (usually http://localhost:5173)

## Features

- 35+ AI tools across 8 categories
- Dark blue theme with gradients
- Category filtering
- Responsive design
- Direct links to each tool's website

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
